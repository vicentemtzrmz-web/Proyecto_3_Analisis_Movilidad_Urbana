# Proyecto_3_Analisis_Movilidad_Urbana
** Descripción:** Se realizó un análisis que nos permitía conocer si la movilidad urbana en Latinoamérica influenciaba la productividad económica. Se trabajo con 2 Datasets [TomTom Traffic Index y OECD Cities] con mas de 100K entradas. 

**Titulo:** Detección de patrones y performance por región, para la toma de decisiones. 
- **Desafío:** El cliente no podía asegurarse de que la movilidad urbana tenia un impacto directo en la economía de distintas ciudades latinoamericanas. 
- **Proceso:** Al tener mas de 100K entradas, el asegurarse de la calidad de datos era esencial, asi como identificar claves primarias para poder hacer un join correcto sin duplicados. Después tuve que tratar valores nulos asi como estandarizar fechas y formatos de columnas para un join correcto.
- **Resultado:** Se logró comprobar con ejemplos verídicos como una movilidad urbana no solo generaba trafico y retrasos, sino que tenia un impacto directo en la productividad económica.
